# V100 standalone NVFP4 QPN T187/T508 extension — 2026-10-29

**Scope and decision:** Single-expert *synthetic* projection correctly handles genuine 187- and 508-row **geometry** without truncation, and a single launch is faster than breaking the same QPN projection into 32-row chunks. This supports a separate real-weight and real-activation benchmark, **not** any inference/production change.

- Source branch: `qpn/large-route-probe`; measured source commit `70e648ce9a59307a955156e141452a29284d727c`, [successful V100 run **40972507332**](https://github.com/mylordmonkeyman/Strata-V100/actions/runs/40972507332), aggregate artifact **12940977053**.
- Synthetic deterministic native GGUF NVFP4 projection `n=1280,k=2560`, 1,843,200 compressed weight bytes (fits V100 L2), input FP16, output FP32, `split_k=4`, `fast_decoder=1`, `token_tile=16`. Ordinary CUDA-event mean over 40 iterations. Same exact weights/activations for full and segmented projection. Device `sm_70`. The comparison is **QPN vs QPN**, not MMQ.
- T=187 and T=508 are actual *group sizes* in the private 16-expert sample (full weights/activations remain private) but the data in **this geometry test** are deliberately synthetic. Current experimental full-model engine routing still only chooses T17–32; `qpn::supported` limit to 512 exists on this isolated branch only.

Full and segmented **bitwise equal**, including changed-input CUDA Graph replay affecting both a mid and last genuine row; finite outputs, untouched output guards. Compute Sanitizer **memcheck 0 errors**, **racecheck 0 hazards/0 warnings** on T187 and T508. The non-sanitized 33–128 geometries passed the same extension run as well.

The next independent real sample uses [workflow `qpn-huge-mixed-real.yml`](https://github.com/mylordmonkeyman/Strata-V100/actions/workflows/qpn-huge-mixed-real.yml) and `--qpn-min 129 --qpn-max 512`, selecting precisely the actual **187 and 508 row** experts (695/1,100 routed rows), leaving all fourteen other captured experts with MMQ. Both arms use the same private SHA-verified 16-expert weights/activations and exact selected permutation. It must pass sampled independent GGUF FP64 oracle, CUDA Graph changed input, canaries, memcheck and racecheck, and report both ordinary and CUDA Graph speed. **A model speedup is not implied.**

No changes to `main`, production default, model pack/cache, host driver, runner privileges, services, or active full-model routing predicate.
