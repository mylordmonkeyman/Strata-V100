# Single-V100 experimental long-row QPN 33–128 geometry qualification (2026-10-29)

**Result:** Standalone CUDA QPN projection at 33–128 rows passed bitwise parity with the existing 32-row segmented implementation, changed-input CUDA Graph replay, finite results and output guards. One large-row launch is 1.22–1.44× faster than multiple 32-row launches in this synthetic workload. **This is not evidence of speedup against W4A8/MMQ or of a model-level benefit.**

- Branch: `qpn/large-route-probe` (independent of experimental full-model `qpn/performance-first`); source commit `f02643c27b7b72437e14c13f763667d9a5d14b91`, [successful V100 run 40970319774](https://github.com/mylordmonkeyman/Strata-V100/actions/runs/40970319774), aggregate artifact ID **12940078380**. - **Synthetic** deterministic GGUF NVFP4 (1,843,200 bytes = one gate/up weight projection), FP16 activations, output FP32, `N=1280,K=2560`, splitK=4, fast decoder, token tile=16, one V100. This fits in 6 MiB L2 and does **not** isolate cold-weight or PCIe transfer effects. Cuda-event means across 64 repetitions include launch submission gaps.
- Segmented reference performs the same projection using contiguous chunks of ≤32 distinct activation rows in multiple launches. Whole launch uses `grid.z` to cover all rows; the comparison does **not** establish kernel correctness against independent MMQ or dequantization math.
